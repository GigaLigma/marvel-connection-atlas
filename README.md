# Marvel Connection Atlas

An **unofficial fan-made interactive reference map** of 200 Marvel properties and 251 story relationships, centered on the Marvel Cinematic Universe.

Includes an interactive graph, search, branches, release-versus-broad-story-order lists, continuity caveats, obscure shorts and comics, and external-universe crossover links.

## Preview

Open `index.html` in a modern browser. The site is self-contained and works without a build process or additional JavaScript packages. The overview links point to `marvel-overview.svg` and `marvel-overview.png` in the same directory.

## Publish with GitHub Pages (free)

1. Sign in to https://github.com or create a free account.
2. Create a **public** repository named `marvel-connection-atlas` (or your preferred name).
3. Upload the **contents** of this directory, including `index.html`, `marvel-overview.svg`, `marvel-overview.png`, `README.md`, and `.nojekyll`, to the **root** of the repository. Commit the new files to the `main` branch. Do not upload the ZIP file without extracting it.
4. Open **Settings → Pages** within the repository.
5. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, Folder to **/(root)**, then **Save**.
6. GitHub publishes the site at `https://YOUR-GITHUB-USERNAME.github.io/marvel-connection-atlas/`. On the Pages screen, use **Visit site** to confirm the actual public URL. Initial publication can take several minutes.

You can update the map later by replacing `index.html` and committing the change; the public URL stays the same. For more information: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Site notes

- The 200 entries represent individual films, series/seasons, tie-in comics, shorts and other relevant media; they are not all part of one universe.
- Some legacy-Marvel-TV continuity links are contested or not conclusively established. Non-MCU adaptations are included only where relevant to MCU crossovers, parallels, or multiverse connections.
- Events and chronology reflect research through **October 28, 2026**. The site is not automatically updated.
- No API keys, analytics, cookies, user accounts, ads, or external code/CDNs are required.
- The source URLs listed within the site are external reference links and may change.
